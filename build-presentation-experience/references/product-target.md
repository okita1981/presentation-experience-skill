# Product target

The product is a Skill-assisted production practice: a human and Codex turn an existing document
into a presenter-operated HTML experience that makes the speaker's explanation clearer than the
source alone.

The shared asset is the process, verification, and craft vocabulary. It is not a SaaS renderer or
a fixed template library. The output remains a portable offline HTML file or ZIP.

## Success boundary

The Skill is not proven until structurally different documents repeatedly produce experiences that
humans judge ready to show. Directional praise, technical correctness, or one successful mechanism
does not establish generality.

Development history belongs in repository documentation, not in execution references.
