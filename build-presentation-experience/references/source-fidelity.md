# Source fidelity

## Provenance classes

- SOURCE: verbatim source content or an unaltered source asset.
- TRANSFORMED_SOURCE: faithful reformatting, cropping, ordering, or arithmetic explicitly supported
  by the source.
- PRESENTER_GUIDANCE: information for the speaker, never audience-facing by default.
- GENERATED_CLAIM: an added assertion; prohibited unless the human explicitly supplies and approves it.

Track source references for every audience-facing text, metric, image, relation, formula, and
conclusion. Keep number + unit + label atomic.

## Brand evidence

Read recurring colors, typography, logo/marks, imagery, line/shape language, whitespace, density,
and tone. Distinguish source evidence from a fallback. A theme color unused in actual content is not
automatically a brand accent. A repeated color is not automatically a semantic category.

## Coverage

Classify every source page as included, merged, supporting, or excluded. A page shown only in a
source drawer is not represented in the experience. Excluding unique content requires a reason and
human-visible disclosure.

## Fidelity boundary

Faithful content can still be poor display copy. After fidelity is established, apply the audience
copy and visual-meaning reviews independently.
